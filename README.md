# ☕ Coffee Sales Dashboard

An interactive Excel dashboard analyzing 1,000 coffee bean orders (2019–2022), built by combining orders, customers and products data into one clean dataset.

![Dashboard](dashboard.png)

## 🛠️ Tools & Techniques
- **XLOOKUP** and **INDEX + MATCH** to combine data from three tables
- **Nested IF** formulas and **custom number formats** for data cleaning
- **Excel Tables**, **PivotTables** and **PivotCharts**
- **Timeline** and **Slicers** (roast type, size, loyalty card) connected to all charts

## 🔍 Key Insights
- **Total sales:** $45,134
- **The United States** generates **79%** of revenue, followed by Ireland and the UK.
- **Robusta** has the lowest sales of the four coffee types.
- **Loyalty card holders** account for **46%** of sales.

## 📁 Dataset
[Coffee Bean Sales Raw Dataset](https://www.kaggle.com/datasets/saadharoon27/coffee-bean-sales-raw-dataset) (Kaggle). Project idea from Mo Chen's YouTube tutorial.
